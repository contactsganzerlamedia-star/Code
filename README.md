# Sganzerla Media

Marketing website for Sganzerla Media, built with [Next.js](https://nextjs.org) and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Structure

- `src/app` — root layout, global styles, and the home page
- `src/components` — page sections (Header, Hero, Services, Work, About, Testimonials, Contact, Footer)

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run start` — run the production build
- `npm run lint` — run ESLint

## Deploy

The easiest way to deploy is [Vercel](https://vercel.com/new), from the creators of Next.js. See the [deployment docs](https://nextjs.org/docs/app/building-your-application/deploying) for other options.
